# Trivia-RPG — Game Design Document

Design document for **Trivia-RPG**, a single-player RPG with Twitch chat integration
(chatters vote on answers and influence the game).

The full design lives in [Trivia RPG planning doc.md](./Trivia%20RPG%20planning%20doc.md).

## Elevator pitch

Dethrone the evil king and his lackeys through bar trivia battles. Questions are your
ammunition, Bar Badgers are your permanent progression, HP is how much you've learned,
and coins run the economy. Built in Godot 4, with Twitch chat able to vote on answers.

## Status

Early design. Server backend is a Namazu Elements Element (Java); client is Godot 4.4.1.
